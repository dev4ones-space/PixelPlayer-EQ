# PixelPlayer FX
A fork of [PixelPlayer](https://github.com/PixelPlayerHQ/PixelPlayer) with support for audio processing by app like [ViPER FX](https://github.com/likelikeslike/ViPERFX_RE)
## Currently works with:
- **[ViPER FX Reverse Engineered](https://github.com/likelikeslike/ViPERFX_RE)**: **works fully**
- **[ViPER FX Material 3 Redesign]()**: **works fullyr** _(a original ViPER FX Fork that is recommended to use for HIDL devices)_
- _others are just not tested, if anything - report if doesn't work to GitHub Issues & Email_
## Building from repo _(for Unix-like OS)_
1. Clone the repo & `cd` into:
```git clone https://github.com/dev4ones-space/PixelPlayer-EQ.git && cd PixelPlayer-EQ```
2. Build:
- **With your keys** _(from local.properties)_: ```bash build.sh```
- **Debug keys** _(works just fine, mainly for private use)_: ```bash build.sh --easy-build```
